하루하나 0.1.11-beta / 2026-10-13

수정 사항
- 말풍선 스킨에 메뉴 아이콘이 없으면 내장 기본 아이콘을 사용합니다.
- '데스크톱의 기본 표시'는 최초 배치 순서만 정합니다. 기존에 저장된
  캐릭터 배치를 무효화하지 않으며, 구 버전의 빈 배치는 한 번 자동 복구합니다.
- 팩의 대기 대사와 대화는 오래된 AI 대사 캐시보다 먼저 사용합니다.
- 지정된 시작 인사와 종료 인사를 AI 생성 결과보다 우선 사용합니다.
- API가 없거나 요청에 실패할 때 종료 인사를 '또 봐.'로 고정하던 경로를 수정했습니다.
- 크리에이터 미리보기는 앱에 저장된 캐릭터의 모니터를 따르며, 위치를 재계산해
  반복 갱신으로 밀리거나 겹치지 않도록 했습니다. 앱의 저장 위치는 변경하지 않습니다.
- 메뉴 첫마디/종료 인사를 대사 그룹으로 편집할 수 있습니다.
- 대화 추가/삭제, 발화별 내용/화자/표정 편집을 지원합니다.
- 현재 그룹 또는 모든 캐릭터의 전체 대사를 확인 후 비울 수 있습니다.
- 일괄 생성 전에 생성할 대사 그룹과 대화를 선택할 수 있습니다.
  선택한 그룹 중 비어 있는 그룹만 생성하며 기존 대사는 덮어쓰지 않습니다.
  기존 프로필 보완/다국어 번역 단계는 유지됩니다.
- AI 설정에 'Gemini 모델 직접 입력'을 추가했습니다. 해당 API 키에서 사용 가능한
  텍스트 생성 모델 ID를 입력하세요. 기존 OpenRouter 직접 입력도 유지됩니다.
  모델 제공 여부: https://ai.google.dev/gemini-api/docs/models

AI 일일 한도 제보에 대한 확인
프로그램 자체에 일일 API 호출 한도 설정은 없고 제공자에서 한도를 관리합니다.
429 오류는 성공 대사로 처리하지 않습니다. 다만 이미 생성해 저장한 AI 대사는
추가 API 호출 없이 재생될 수 있습니다. 지정한 대기 대사가 캐시에 가려지던
문제는 수정했습니다. 저장된 대사가 나온다는 사실만으로 새 과금/호출이
발생했다는 뜻은 아닙니다. 실제 계정의 한도 소진 상태로는 검증하지 않았습니다.

검증
- Godot 4.6.3으로 기존 회귀/크리에이터/말풍선/친밀도/터치/스크롤/데스크톱 테스트.
- 별도 제보 회귀 테스트: 기본 캐릭터 순서 변경, 빈 배치 복구, 지정 대사 우선순위,
  아이콘 복구, 대화 편집 후 내보내기/다시 열기, 전체 삭제, 생성 그룹 선택,
  Gemini 사용자 지정 모델 유지, 미리보기 반복 배치와 위치 저장 분리.
- Windows 실제 창에서 위치 복원과 미리보기 겹침을 검증했습니다.

남은 실사용 확인
- 테스트 환경에서 모니터가 하나만 감지되었습니다. 실제 듀얼 모니터와 서로 다른
  배율의 모니터 간 배치는 추가 확인이 필요합니다.
- 실제 API 키를 사용한 생성, 제공자 한도 소진 및 503 오류는 재현하지 않았습니다.
- 구 버전에서 실제 자동 업데이트하는 과정은 이번에 재현하지 않았습니다.

설치
기존 앱과 크리에이터를 종료한 뒤 새 ZIP을 별도 폴더에 풀어 실행해 보세요.
기존 외부 characters, 사용자 말풍선/폰트는 별도로 보관하세요.
개인 저장 데이터 폴더를 삭제할 필요는 없습니다. 그 폴더는 초기화하지 마세요.
